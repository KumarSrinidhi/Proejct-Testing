# Campus Runner — Site Vision

**Stitch Project ID:** 9271387703974283514

## 1. Project Overview

Campus Runner is a platform connecting students on campus who need tasks/errands done with runners willing to complete those tasks for a fee. It features a customer-facing mobile app and a runner-facing mobile app.

**Core value proposition:** Fast, reliable on-campus errand delivery between students.

## 2. Target Audience

- **Customers:** Students who need quick on-campus errands run (food pickup, item delivery, printing, etc.)
- **Runners:** Students looking to earn money by completing tasks on campus

## 3. Design Language

- **Style:** Modern, energetic, campus-friendly
- **Tone:** Friendly, trustworthy, efficient
- **Device:** Mobile-first (MOBILE)
